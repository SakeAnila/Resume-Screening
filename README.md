
# 🧠 Resume Screening using Machine Learning 

---

## ❓ Why do we need Resume Screening?

Recruitment teams often receive thousands of resumes for a single job posting. Manually reviewing each one is time-consuming and inefficient. Traditionally, resumes are collected, categorized, and passed on to hiring teams—this process becomes cumbersome when dealing with large volumes.

To automate and speed up this task, we introduce an intelligent Resume Screening system using **Machine Learning** and **Natural Language Processing (NLP)** in **Python**. It helps complete what would normally take days in just minutes.

---

## 🧾 Introduction

**Resume screening** is the process of determining whether a candidate meets the qualifications for a role based on education, experience, and skills listed on their resume. The goal is to decide whether to move a candidate forward in the hiring process or reject them.

---

## 🛠 Modules & Libraries

### 📦 Modules
- **KNN (K-Nearest Neighbors):** A supervised learning technique used for classification based on proximity to neighbors.
- **NLP (Natural Language Processing):** Helps machines understand and interpret human language.

### 📚 Libraries
- `NumPy`: For numerical operations and matrix support.
- `Pandas`: For structured data handling and analysis.
- `Matplotlib` & `Seaborn`: For data visualization.
- `SciPy`: For scientific computations.
- `Scikit-learn`: For building machine learning models.
- `NLTK`: For advanced text processing and analysis.

---

## ⚙️ Functionality of Application

The system evaluates resumes based on:
- Work Experience  
- Education  
- Skills and Knowledge  
- Personality Traits  
- Competencies  

It compares candidate qualifications to job requirements using ML algorithms.
